# Gravilog

Gravilog 是一个单文件个人日志 / 笔记编辑器。它没有构建流程、没有后端服务，直接打开 `index.html` 就可以写作。内容默认保存在浏览器本地，也可以链接一个 JSON 文件，用于云盘同步和手动备份。

## 快速开始

Windows 上推荐双击 `start-gravilog.bat` 启动。脚本会自动启动本地 HTTP 服务，并打开类似下面的地址：

```text
http://localhost:端口/index.html
```

也可以直接用浏览器打开 `index.html`，但文件链接持久化在 `file://` 打开方式下可能不稳定。

首次加载需要联网获取 KaTeX 和 highlight.js 的 CDN 资源。浏览器缓存后，后续加载会更快。

建议使用 Chrome 或 Edge。如果需要“链接文件”并自动保存到本地 JSON 文件，必须使用支持 File System Access API 的浏览器。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 富文本编辑 | 支持加粗、斜体、下划线、删除线、高亮、文字颜色等 |
| Markdown 快捷输入 | 输入常见 Markdown 语法后自动转换列表、引用、标题、待办和代码块 |
| LaTeX 公式 | 支持 `$...$` 行内公式和 `$$...$$` 块级公式 |
| 代码块 | 支持语法高亮、语言选择、Tab 缩进和自动保持缩进 |
| 图片 | 支持插入、粘贴、对齐、缩放、双击预览 |
| 表格 | 支持插入表格、增删行列、删除整表 |
| 演示模式 | 全屏展示选中内容，鼠标会变成红色激光笔 |
| 日历 | 支持年、月、周、日视图，滚轮缩放切换，月视图显示农历和节日 |
| 日程记录 | 日视图添加事项记录，按分类着色，支持删除、拖动改时间、上下边缘改时长 |
| 深色模式 | 深色模式覆盖编辑器、日历、弹窗和同步状态 |
| 撤销 / 重做 | 支持 Ctrl+Z 撤销、Ctrl+Y 重做，最多 80 步历史 |
| 自动保存 | 保存到 `localStorage`，可选同步写入链接的 JSON 文件 |

## 编辑体验

编辑区采用居中阅读宽度，左右保留留白，避免正文在大屏上铺得过宽。编辑区滚动条默认弱化，悬停时轻微显示，减少正文和留白之间的突兀边界。

鼠标位于编辑区域正文或两侧留白时，滚轮都会滚动正文内容，并保持重力滚动动画效果一致。

顶部工具栏保留常用格式和插入能力：撤销、重做、加粗、斜体、下划线、删除线、表格、图片、高亮、文字颜色、深色模式和演示模式。无序列表、有序列表、引用、代码块、待办事项等结构化内容主要通过编辑时直接输入 Markdown 快捷语法创建，因此不再占用工具栏按钮。

工具栏操作会记住编辑区中最后的光标位置。点击插入表格、图片、高亮等按钮时，会先恢复到原编辑位置再执行操作。

## Markdown 快捷输入

输入下面内容后按空格或回车会自动转换：

| 输入 | 结果 |
| --- | --- |
| `# ` | 一级标题 |
| `## ` | 二级标题 |
| `- ` 或 `* ` | 无序列表 |
| `1. ` | 有序列表 |
| `- [ ] ` | 未完成待办 |
| `- [x] ` | 已完成待办 |
| `> ` | 引用 |
| `` ``` `` 或 `` ```python `` | 代码块 |

输入闭合语法后会自动渲染：

| 输入 | 结果 |
| --- | --- |
| `**bold**` | 加粗 |
| `*italic*` | 斜体 |
| `` `code` `` | 行内代码 |
| `$E=mc^2$` | 行内公式 |
| `$$\int_0^1 x dx$$` | 块级公式 |

## 代码块

代码块支持：

- 右上角下拉菜单选择语言。
- 实时语法高亮。
- `Tab` 插入 4 个空格。
- 选中多行后按 `Tab` 批量缩进。
- `Shift+Tab` 反缩进。
- 在代码块中按回车会自动继承当前行缩进。

支持的语言包括 Text、Python、JavaScript、TypeScript、Java、C++、C#、Go、Rust、Bash、SQL、JSON、YAML、XML、HTML、CSS、Markdown。

## 表格

点击工具栏表格按钮可以插入表格。点击任意单元格后会出现表格工具栏，可执行：

- 上方 / 下方插入行
- 左侧 / 右侧插入列
- 删除行
- 删除列
- 删除整张表

插入列和删除列会同步处理标题行与正文行，避免表头和内容列数不一致。

## 图片

支持通过工具栏插入图片，也支持直接粘贴图片。

插入或粘贴图片后会立即保存。较大的非 GIF 图片会自动压缩到适合笔记保存的尺寸，以降低浏览器本地缓存和云文档写入压力。

点击图片后可以左对齐、居中、右对齐、缩放到 25% / 50% / 75% / 100% 或删除图片。双击图片可以打开全屏预览。

## LaTeX

- 输入 `$...$` 渲染行内公式。
- 输入 `$$...$$` 渲染块级公式。
- 点击已经渲染的公式可以重新编辑。

## 演示模式

选中文档中的一段内容后，点击工具栏演示按钮进入全屏展示。演示模式会复制选区内容，并尽量保持编辑区中的原有格式：

- 图片保留对齐、尺寸和圆角风格。
- 表格保留边框、单元格间距和表头样式。
- 行内公式和块级公式保留 KaTeX 渲染后的展示效果。
- 代码块继续使用语法高亮。

进入演示模式后，普通鼠标光标会隐藏，页面上会显示一个红色发光激光点跟随鼠标移动，用于展示时指示重点。激光点不会拦截点击。

## 日历

右侧日历采用滚轮缩放式导航：

- 鼠标上滑：`年 → 月 → 周 → 日`
- 鼠标下滑：`日 → 周 → 月 → 年`

视图切换有轻微淡入和位移动画，避免生硬跳变。

### 年视图

年视图一行显示两个月，共六行，铺满日历区域。上半年和下半年之间有一条很淡的分隔线。年视图中的小月历保持简洁，不显示周数、农历和节日文字。

### 月视图

月视图显示标准月历，并在每周左侧显示周数。点击周数进入周视图，点击日期进入日视图。

月视图会显示中国农历和常见节日：

- 普通日期显示农历日，例如 `初五`、`廿三`。
- 农历初一显示农历月份，例如 `正月`、`八月`。
- 节日优先显示并用红色强调，例如春节、元宵、端午、中秋、重阳、腊八、除夕、元旦、清明、劳动节、国庆等。

### 周视图

周视图显示 7 天时间轴，左上角显示周数。时间从早上 `06a` 开始，依次显示到次日 `05a`。事项只以分类颜色块呈现，不显示文字控件；悬停可通过浏览器提示查看时间和文本。

### 日视图

日视图时间轴从早上 `06:00` 开始，依次显示到次日 `05:00`，并铺满可用高度。可以添加事项记录：

- 选择开始时间。
- 选择分类：`Familiy`、`work`、`Sleep`、`Personal`。
- 输入事项文本并添加。
- 拖动事项块整体可调整开始时间。
- 拖动事项块上下边缘可调整起止时间。
- 调整粒度为 15 分钟。
- 默认时长为 30 分钟。
- 可以删除事项记录。

分类颜色：

| 分类 | 颜色 |
| --- | --- |
| Familiy | 红色 |
| work | 绿色 |
| Sleep | 紫色 |
| Personal | 黄色 |

日视图和周视图的连续时间块会按每小时分隔，视觉上可以区分不同小时段，不会黏成一整条。

## 数据保存

### 本地自动保存

普通输入会先标记为待保存，并在短防抖后保存到 `localStorage`，减少大文档和图片较多时的输入卡顿。页面失焦、刷新或隐藏时会尽量立即保存一次，降低内容丢失风险。

图片、表格、代码块、日历事项等结构化操作会立即保存。

### 链接文件

点击右侧“链接文件”可以选择一个 JSON 文件，例如云盘同步目录中的 `diary.json`。

链接文件后：

- 编辑内容会写入该 JSON 文件。
- 页面会把文件句柄保存到 IndexedDB。
- 刷新后会显示挂载面板，用于加载上次同步文件。
- 如果浏览器仍保留写权限，会自动继续写入。
- 如果浏览器要求重新授权，界面会提示已记住文件，需要点击“链接文件”恢复写入。
- 如果本地版本明确比云盘版本更新，会自动写回云盘文件。
- 如果云盘版本明确比本地版本更新，会自动使用云盘版本。
- 如果本地存在未同步内容，同时云盘也发生变化，会进入冲突保护，不会自动覆盖任一版本。

### 冲突保护与合并

多设备编辑时，如果 Gravilog 检测到本地未同步版本和云盘版本都发生过变化，会打开冲突合并面板：

- 左侧显示本地未同步版本。
- 右侧显示云盘版本。
- 中间是可编辑的合并版本。
- 可以从本地或云盘载入合并起点，再手动整理为最终版本。
- 点击“保存合并版本”后，会生成新的 `savedAt`，更新本地缓存，并写回云盘文件。

冲突发生时，Gravilog 会把本地和云盘版本备份到浏览器的 `diary_conflict_backup`，避免合并前丢失任一版本。

### 状态显示

右侧“存储与同步”区域会显示当前保存情况：

- `链接`：显示未挂载、待挂载、待授权或当前文件名。
- `云端`：显示未保存、仅本地、待同步、保存中或当前文件名。

### 导出 / 导入

- 导出会生成 `diary_YYYY-MM-DD.json`。
- 导入可以恢复已有 JSON 数据。

### 数据格式

```json
{
  "doc": "<html>editor content</html>",
  "dates": ["2026-05-13", "2026-05-12"],
  "stats": {
    "2026-05-13": 1200
  },
  "todos": {
    "2026-05-13": [
      {
        "id": "example",
        "hour": 9,
        "start": 540,
        "duration": 30,
        "category": "work",
        "text": "Prepare notes"
      }
    ]
  },
  "savedAt": "2026-05-13T10:30:00.000Z"
}
```

`todos` 中的 `start` 和 `duration` 以分钟为单位。旧的按小时事项会自动兼容迁移为对应小时开始、30 分钟时长。

## 浏览器支持

| 浏览器 | 支持情况 |
| --- | --- |
| Chrome / Edge | 推荐，支持链接文件 |
| Firefox / Safari | 可编辑和本地保存，但通常不支持链接文件 |

File System Access API 是浏览器能力，不是 Gravilog 自己实现的文件权限系统。因此不同浏览器、不同打开方式、不同隐私设置下，文件链接的持久性会有差异。

为了让文件句柄更稳定地持久化，建议通过 `http://localhost` 或 HTTPS 打开页面，而不是直接双击 `index.html` 使用 `file://` 打开。
