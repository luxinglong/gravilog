# Gravilog

Gravilog 是一个单文件个人日志 / 笔记编辑器。它没有构建流程、没有后端服务，直接打开 `index.html` 就可以写作。内容默认保存在浏览器本地，也可以链接一个 JSON 文件，用于云盘同步和手动备份。

## 快速开始

Windows 上推荐双击 `start-gravilog.bat` 启动。脚本会自动启动本地 HTTP 服务，并打开类似下面的地址：

```text
http://localhost:端口/index.html
```

也可以直接用浏览器打开 `index.html`，但文件链接持久化在 `file://` 打开方式下可能不稳定。

首次加载需要联网获取 KaTeX 和 highlight.js 的 CDN 资源。浏览器缓存后，后续加载会更快。

建议使用 Chrome 或 Edge。如果需要“链接文件”自动保存到本地 JSON 文件，必须使用支持 File System Access API 的浏览器。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 富文本编辑 | 支持加粗、斜体、下划线、删除线、列表、引用等 |
| Markdown 快捷输入 | 输入常见 Markdown 语法后自动转换 |
| LaTeX 公式 | 支持 `$...$` 行内公式和 `$$...$$` 块级公式 |
| 代码块 | 支持语法高亮、语言下拉选择、Tab 缩进、自动保持缩进 |
| 图片 | 支持插入、粘贴、对齐、缩放、双击预览 |
| 表格 | 支持插入表格、增删行列、删除表格 |
| 演示模式 | 支持全屏展示选中内容，并保留图片、表格、公式等格式 |
| 待办事项 | 支持复选框和回车续写 |
| 日历 | 支持日、周、月、年视图，自动标记有内容的日期 |
| 日夜模式 | 暗色模式使用更现代的深色层次和高对比日历 |
| 撤销 / 重做 | 支持 Ctrl+Z 撤销、Ctrl+Y 重做，最多 80 步历史 |
| 自动保存 | 轻量防抖保存到 localStorage，可选同步写入链接文件 |

## 编辑体验

编辑区采用居中阅读宽度，左右保留留白，避免正文在大屏上铺得过宽。顶部工具栏默认与左侧编辑工作区居中对齐，而不是按整个浏览器窗口居中。

右侧日历栏为响应式宽度。日视图和周视图会根据窗口高度自动铺满，当前时间线使用百分比定位，窗口大小变化后仍能保持准确位置。

编辑区滚动条默认弱化，悬停时才轻微显示，减少正文和留白之间的突兀边界。

工具栏操作会记住编辑区中最后的光标位置。点击插入表格、引用、图片、代码块、待办等按钮时，会先恢复到原编辑位置再插入，避免按钮抢焦点后内容跳到文档开头。

## Markdown 快捷输入

输入下面内容后按空格会自动转换：

| 输入 | 结果 |
| --- | --- |
| `# ` | 一级标题 |
| `## ` | 二级标题 |
| `- ` 或 `* ` | 无序列表 |
| `1. ` | 有序列表 |
| `- [ ] ` | 未完成待办 |
| `- [x] ` | 已完成待办 |
| `> ` | 引用 |

输入闭合语法后会自动渲染：

| 输入 | 结果 |
| --- | --- |
| `**bold**` | 加粗 |
| `*italic*` | 斜体 |
| `` `code` `` | 行内代码 |
| `$E=mc^2$` | 行内公式 |
| `$$\int_0^1 x dx$$` | 块级公式 |

## 代码块

输入 `` ``` `` 或 `` ```python `` 后按回车，可以创建代码块。

代码块支持：

- 右上角下拉菜单选择语言。
- 实时语法高亮。
- `Tab` 插入 4 个空格。
- 选中多行后按 `Tab` 批量缩进。
- `Shift+Tab` 反缩进。
- 在代码块中按回车会自动继承当前行缩进。

支持的语言包括 Text、Python、JavaScript、TypeScript、Java、C++、C#、Go、Rust、Bash、SQL、JSON、YAML、XML、HTML、CSS、Markdown。

## 表格

点击工具栏表格按钮可以插入表格。点击任意单元格后会出现表格工具栏，可执行：

- 上方 / 下方插入行
- 左侧 / 右侧插入列
- 删除行
- 删除列
- 删除整张表

插入列和删除列会同步处理标题行与正文行，避免表头和内容列数不一致。

## 图片

支持通过工具栏插入图片，也支持直接粘贴图片。

插入或粘贴图片后会立即保存。较大的非 GIF 图片会自动压缩到适合笔记保存的尺寸，以降低浏览器本地缓存和云文档写入压力。

点击图片后可以：

- 左对齐
- 居中
- 右对齐
- 缩放到 25%、50%、75%、100%
- 删除图片

双击图片可以打开全屏预览。

## LaTeX

- 输入 `$...$` 渲染行内公式。
- 输入 `$$...$$` 渲染块级公式。
- 点击已经渲染的公式可以重新编辑。

## 演示模式

选中文档中的一段内容后，可以点击工具栏的演示按钮进入全屏展示。演示模式会复制选区内容，并尽量保持编辑区中的原有格式：

- 图片保留对齐、尺寸和圆角风格。
- 表格保留边框、单元格间距和表头样式。
- 行内公式和块级公式保留 KaTeX 渲染后的展示效果。
- 代码块继续使用语法高亮。

## 日历

右侧日历提供四种视图：

| 视图 | 说明 |
| --- | --- |
| 日 | 24 小时时间轴，自动铺满可用高度 |
| 周 | 7 天时间轴，自动铺满可用高度 |
| 月 | 标准月历，有内容的日期显示圆点 |
| 年 | 12 个迷你月历，有内容的日期显示圆点 |

当天会高亮显示。日视图和周视图会显示当前时间线。

## 数据保存

### 本地自动保存

普通输入会先标记为待保存，并在短防抖后保存到 `localStorage`，减少大文档和图片较多时的输入卡顿。页面失焦、刷新或隐藏时会尽量立即保存一次，降低内容丢失风险。

图片、表格、待办、代码块等结构化插入会立即保存，避免刚插入内容后刷新造成丢失。

### 链接文件

点击右侧“链接文件”可以选择一个 JSON 文件，例如云盘同步目录中的 `diary.json`。

链接文件后：

- 编辑内容会写入该 JSON 文件。
- 页面会把文件句柄保存到 IndexedDB。
- 刷新后会显示简化的挂载面板，只保留“加载上次同步文件”按钮。
- 如果浏览器仍保留写权限，会自动继续写入。
- 如果浏览器要求重新授权，界面会提示已记住文件，需要点击“链接文件”恢复写入。
- 如果本地版本明确比云盘版本更新，会自动写回云盘文件。
- 如果云盘版本明确比本地版本更新，会自动使用云盘版本。
- 如果本地存在未同步内容，同时云盘也发生变化，会进入冲突保护，不会自动覆盖任一版本。

### 冲突保护与合并

多设备编辑时，如果 Gravilog 检测到本地未同步版本和云盘版本都发生过变化，会打开冲突合并面板：

- 左侧显示本地未同步版本。
- 右侧显示云盘版本。
- 中间是可编辑的合并版本。
- 可以从本地或云盘载入合并起点，再手动整理为最终版本。
- 点击“保存合并版本”后，会生成新的 `savedAt`，更新本地缓存，并写回云盘文件。

冲突发生时，Gravilog 会把本地和云盘版本备份到浏览器的 `diary_conflict_backup`，避免合并前丢失任一版本。

### 状态显示

右侧“存储与同步”区域会以两行简洁状态展示当前保存情况：

- `链接`：显示 `未挂载`、`待挂载`、`待授权` 或当前文件名。
- `云端`：显示 `未保存`、`仅本地`、`待同步`、`保存中` 或当前文件名。

重要限制：

- 自动恢复写权限受浏览器安全策略限制，网页不能绕过浏览器权限模型。
- 推荐使用 Chrome 或 Edge。
- 为了让文件句柄更稳定地持久化，建议通过 `http://localhost` 或 HTTPS 打开页面，而不是直接双击 `index.html` 使用 `file://` 打开。

### 导出 / 导入

- 导出会生成 `diary_YYYY-MM-DD.json`。
- 导入可以恢复已有 JSON 数据。

### 数据格式

```json
{
  "doc": "<html>editor content</html>",
  "dates": ["2026-05-13", "2026-05-12"],
  "stats": {
    "2026-05-13": 1200
  },
  "savedAt": "2026-05-13T10:30:00.000Z"
}
```

## 工具栏

编辑器聚焦时，顶部工具栏会显示在左侧编辑工作区上方。

| 按钮 | 功能 |
| --- | --- |
| ↩ | 撤销（Ctrl+Z） |
| ↪ | 重做（Ctrl+Y / Ctrl+Shift+Z） |
| B | 加粗 |
| I | 斜体 |
| U | 下划线 |
| S | 删除线 |
| `-` | 无序列表 |
| `1.` | 有序列表 |
| `"` | 引用 |
| 表格 | 插入表格 |
| 图片 | 插入图片 |
| `</>` | 插入代码块 |
| 待办 | 插入待办事项 |
| 水彩笔 | 高亮文本 |
| 演示 | 全屏展示选中内容 |
| 月亮 / 太阳 | 切换日夜模式 |

右侧状态文字：

- `...` 表示正在保存。
- `OK` 表示保存完成。

右侧“存储与同步”状态灯会显示文件挂载状态和云端写入状态。

## 浏览器支持

| 浏览器 | 支持情况 |
| --- | --- |
| Chrome / Edge | 推荐，支持链接文件 |
| Firefox / Safari | 可编辑和本地保存，但通常不支持链接文件 |

File System Access API 是浏览器能力，不是 Gravilog 自己实现的文件权限系统。因此不同浏览器、不同打开方式、不同隐私设置下，文件链接的持久性会有差异。
